# game

The browser game itself. Open any page directly; there is nothing to install.

| Files | What they are |
|---|---|
| `index.html`, `level2-4.html` | four hand-made levels |
| `case.html`, `case2.html`, `case3.html` | random cases of crimes 1, 2 and 3 |
| `case-guard.html` | guard duty: stop the scams before they happen |
| `cases/gen*.js` | seeded case generators |
| `cases/solve*.js`, `cases/check*.js` | reference solvers and fairness checkers |
